💀First Lie: Post-Newtonian corrections (1/2)

\[ \mathbf{a}_{\mathrm{N+1PN+2PN+2.5PN}} = -\frac{Gm}{r^2} \left[ \left( 1+\frac{A_{\mathrm{1PN}}}{c^2} +\frac{A_{\mathrm{2PN}}}{c^4} +\frac{A_{\mathrm{2.5PN}}}{c^5} \right)\mathbf{n} + \left( \frac{B_{\mathrm{1PN}}}{c^2} +\frac{B_{\mathrm{2PN}}}{c^4} +\frac{B_{\mathrm{2.5PN}}}{c^5} \right)\mathbf{v} \right] \]
\[ \boxed{ A_{\mathrm{1PN}} = -(1+3\nu)v^2 +\frac{3}{2}\nu\dot{r}^{\,2} +(4+2\nu)\frac{Gm}{r} } \] \[ \boxed{ B_{\mathrm{1PN}} = -(4-2\nu)\dot{r} } \] \[ \boxed{ \begin{aligned} A_{\mathrm{2PN}}={}& \frac{3}{4}(12+29\nu) \left(\frac{Gm}{r}\right)^2 +\nu(3-4\nu)v^4 +\frac{15}{8}\nu(1-3\nu)\dot{r}^{\,4} \\ &-\frac{3}{2}\nu(3-4\nu)v^2\dot{r}^{\,2} -\left(2+25\nu+2\nu^2\right) \frac{Gm}{r}v^2 \\ &-\frac{1}{2}\nu(13-4\nu) \frac{Gm}{r}\dot{r}^{\,2} \end{aligned} } \] \[ \boxed{ \begin{aligned} B_{\mathrm{2PN}}={}& -\frac{1}{2}\nu(15+4\nu)\dot{r}^{\,3} \\ &+\frac{1}{2}(4+41\nu+8\nu^2) \frac{Gm}{r}\dot{r} \\ &+(2+2\nu)v^2\dot{r} \end{aligned} } \] \[ \boxed{ A_{\mathrm{2.5PN}} = \frac{8}{5}\nu\frac{Gm}{r} \left( 3v^2+\frac{17}{3}\frac{Gm}{r} \right)\dot{r} } \] \[ \boxed{ B_{\mathrm{2.5PN}} = -\frac{8}{5}\nu\frac{Gm}{r} \left( v^2+3\frac{Gm}{r} \right) } \] \[ \boxed{ \mathbf{a}_{\mathrm{2.5PN}} = -\frac{Gm}{r^2} \left[ \frac{A_{\mathrm{2.5PN}}}{c^5}\mathbf{n} + \frac{B_{\mathrm{2.5PN}}}{c^5}\mathbf{v} \right] } \]
  • 1PN: relativistic correction, proportional to $1/c^{2}$
  • 2PN: conservative relativistic correction, proportional to $1/c^{4}$
  • 2.5PN: dissipative correction, proportional to $1/c^{6}$. orbital energy and angular momentum loss through gravitational-wave emission.
  • (3PN, 3.5PN, 4PN, 4.5PN, ...)
